MagicPorts MCP

Ask AI assistants about Veeam ports, generate topology diagrams, and build firewall import files — powered by the same Magic Ports API this app uses.

Prerequisite: install uv (a single binary). The uvx command downloads and runs veeam-ports-mcp automatically — no repo clone needed.

Claude Desktop

Add the server to your Claude Desktop config, then restart Claude Desktop.

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
{{ claudeDesktopConfig }}

Claude Code / VS Code

From a terminal (with the Claude Code CLI available): 

{{ claudeCodeCommand }}

Cursor

Create or edit .cursor/mcp.json in your project (or your global Cursor MCP config) and add: 

{{ cursorMcpConfig }}

Then enable the server in Cursor Settings → MCP, and restart if needed.
